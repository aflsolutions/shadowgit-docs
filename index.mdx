## What is ShadowGit?

ShadowGit is a desktop app that snapshots your projects every few minutes while you work, in a history of its own next to your git repository. Through the ShadowGit MCP server, Claude Code, Cursor and Claude Desktop can read that history: what changed in the last hour, when a file was last touched, what you tried yesterday.

## How it works

ShadowGit keeps each project's snapshots in a separate git repository, `.shadowgit.git`, inside the project. It never touches your own `.git`, and it adds `.shadowgit.git` to your `.gitignore`.

```text
your-project/
├── .git/              # Your own git history, untouched
├── .shadowgit.git/    # ShadowGit's snapshots
├── src/
└── ...
```

- **Snapshots.** ShadowGit takes the first snapshot when you add a project, then a new one every few minutes while files change, sooner after a large change. You can tune the timing in the app's settings.
- **Sessions and checkpoints.** Before your assistant edits several files, it can start a ShadowGit session, which pauses automatic snapshots so its half-done edits don't spread over many snapshots. When it's done, it saves the result as one named checkpoint and ends the session. See [Sessions and checkpoints](/installation#sessions-and-checkpoints).
- **Restore.** In the app you can bring a project back to any snapshot. Changes not yet in a snapshot are backed up first.

## Privacy and security

- **Your code stays on your computer.** Snapshots are stored in your project, and ShadowGit doesn't upload them.
- **The MCP server only talks to the ShadowGit app on your computer.** What your assistant reads through it goes to your AI provider, like any file the assistant opens.
- **Through ShadowGit, your assistant reads and adds checkpoints, nothing else.** It reads the snapshot history with read-only git commands and can add checkpoints to it. Through ShadowGit it can't change your files, your own git repository or existing snapshots.

## Requirements

- The ShadowGit app on macOS 13 or later, Windows 10 or later (64-bit) or Linux (x64 or arm64). Checkpoints need version 0.3.4 or later.
- Git
- Node.js 20 or later, which runs the MCP server
- Claude Code, Cursor, Claude Desktop or another MCP client
