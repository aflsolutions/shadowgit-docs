## Before you start

You need Claude Code ([Get Claude Code](https://code.claude.com/docs)), the ShadowGit app, Node.js 20 or later and Git. See [Before you start](/installation#before-you-start).

## Set up

Run this in a terminal, not inside a Claude Code session:

```bash
claude mcp add --scope user shadowgit -- npx -y shadowgit-mcp-server
```

`--scope user` makes ShadowGit available in all your projects. Then start a new Claude Code session.

## Check that it works

```bash
claude mcp list
```

`shadowgit` should show `✔ Connected`. Inside a session, `/mcp` shows it with its tools. Then ask Claude:

```text
Show me my ShadowGit repositories
```

Claude lists the projects ShadowGit tracks and which one you're working in.

## Using it

Claude Code tells ShadowGit which folder you started it in, so you never name the project: ShadowGit uses the tracked project that contains that folder. For what to ask, see [What to ask](/installation#what-to-ask).

### Skip the permission prompts

Claude Code may ask before it calls a ShadowGit tool. To allow all of them, add `mcp__shadowgit` to the `allow` list in `~/.claude/settings.json`:

```json
{
  "permissions": {
    "allow": ["mcp__shadowgit"]
  }
}
```

You can also manage rules with the `/permissions` command.

## Troubleshooting

### ShadowGit shows "Failed to connect"

1. Run `claude mcp get shadowgit`. Its `Issue:` line says what went wrong.
2. Check `node --version`: the server needs Node.js 20 or later, from the `PATH` Claude Code starts with.
3. The first start downloads the server. Claude Code waits 30 seconds for it; on a slow connection, start Claude Code with a longer timeout, then reconnect from `/mcp`:
   ```bash
   MCP_TIMEOUT=60000 claude
   ```

### Claude doesn't use ShadowGit

Claude Code loads MCP servers when a session starts. Start a new session after adding ShadowGit, and check that `/mcp` lists it.

### ShadowGit only works in one project

You added it without `--scope user`, so it's only available in the folder where you ran the command. Add it again with the scope:

```bash
claude mcp remove shadowgit
claude mcp add --scope user shadowgit -- npx -y shadowgit-mcp-server
```

For problems that aren't specific to Claude Code, such as "ShadowGit isn't running", see [Troubleshooting](/installation#troubleshooting).
