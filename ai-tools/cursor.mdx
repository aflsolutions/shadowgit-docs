## Before you start

You need Cursor ([Get Cursor](https://cursor.com)), the ShadowGit app, Node.js 20 or later and Git. See [Before you start](/installation#before-you-start).

## Set up

1. Open `~/.cursor/mcp.json`, creating it if needed, and add ShadowGit under `mcpServers`:
   ```json
   {
     "mcpServers": {
       "shadowgit": {
         "command": "npx",
         "args": ["-y", "shadowgit-mcp-server"]
       }
     }
   }
   ```
   If the file already lists other servers, add the `shadowgit` entry next to them. To use ShadowGit in one project only, put the entry in `.cursor/mcp.json` inside that project instead.
2. Save the file and restart Cursor.

## Check that it works

Open **Customize → MCPs** in Cursor's sidebar: `shadowgit` should be listed with its tools. Then ask the Agent:

```text
Show me my ShadowGit repositories
```

It lists the projects ShadowGit tracks.

## Using it

The Agent uses ShadowGit's tools on its own when your question needs them. By default Cursor asks for your approval before it runs one; see [Cursor's MCP docs](https://cursor.com/docs/mcp) to change that.

When ShadowGit tracks more than one project, name the one you mean in your question, as in "What changed in webshop in the last hour?". For more, see [What to ask](/installation#what-to-ask).

## Troubleshooting

### ShadowGit isn't listed or doesn't connect

1. Check that `~/.cursor/mcp.json` is valid JSON and that you restarted Cursor after saving it.
2. Open the Output panel (`Cmd+Shift+U` on macOS, `Ctrl+Shift+U` on Windows and Linux) and choose **MCP Logs**. Errors from the server show up there.
3. Check `node --version`: the server needs Node.js 20 or later. If Cursor can't find `npx`, make sure Node.js is on the `PATH` Cursor starts with, then restart Cursor.

For problems that aren't specific to Cursor, such as "ShadowGit isn't running", see [Troubleshooting](/installation#troubleshooting).
